# The Nemeth Cookbook

A personalized, searchable collection of healthy weeknight recipes, weekly meal plans, grocery lists, snacks, sandwiches, and Nemeth family favorites.

## Website

This repository is designed for GitHub Pages. The website entry file is `index.html`.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
